# FM Trait Helper

Enter a Football Manager player's attributes and get the player traits that best suit them.
Trait/attribute data comes from [passion4fm](https://www.passion4fm.com/football-manager-player-traits/), weighted key 9 / secondary 4 / other 1.

## Scripts

- `npm start` — dev server at http://localhost:3000
- `npm test` — run tests (Vitest)
- `npm run build` — production build in `dist/`
- `npm run preview` — serve the production build
